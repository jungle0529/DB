# 고객 DB 관리 시스템

다양한 고객 데이터를 정리하고 빠르게 검색할 수 있는 단일 HTML 웹앱입니다.
별도 서버나 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

> **포함 파일**: `index.html`(앱) + `seed-data.js`(초기 데이터). 두 파일은 **같은 폴더에 함께** 두어야 합니다.
> 처음 열 때 `seed-data.js`의 데이터(업로드한 `건설사DB정리.xlsx`의 4개 시트 → 약 1,180명)가 자동으로 들어갑니다.
> 이후에는 브라우저에 저장된 내 데이터를 사용하며, 시드는 다시 덮어쓰지 않습니다.

## 주요 기능

- **데이터 입력 (3가지 방식)**
  - 직접 입력: 폼으로 한 명씩 등록
  - 엑셀 파일: `.xlsx / .xls / .csv` 끌어다 놓기 또는 선택
  - 표 붙여넣기: 엑셀/구글시트에서 복사한 표를 그대로 붙여넣기
- **데이터 항목**: 회사 · 이름 · 직책 · 부서 · 휴대폰 · 이메일 · 회사전화 · 주소 · 협업 업무 · 소통 활동기록(여러 건) · 키워드 · 비고 · 구분(출처)
- **검색**: 이름 · 회사 · 직책 · 부서 · 연락처 · 협업 · 활동기록 · 키워드별 또는 전체 검색
  (검색어가 들어간 사람 카드가 모두 표시되고 일치 부분이 하이라이트됩니다)
- **카테고리**: 건설 · 전시 · 하드웨어 · 대행 · 시행 · 기타(직접입력) 6종으로 분류하고 카테고리별로 모아 보기
  (가져온 데이터는 분야/유형 정보로 자동 분류하며, 신호가 없으면 출처 기준 기본값으로 배정됩니다. 직접입력은 기본 ‘기타’이며 언제든 수정 가능)
- **출처**: 원본 시트(건설/건설_제외/중개업/포럼초대) 정보는 카드에 함께 표시·검색됩니다
- **협력 프로젝트**: 각 회사/담당자가 올림플래닛과 협업한 프로젝트(명/코드·기간·역할·상태·비고)를 기록하고, ‘협력 프로젝트’ 탭에서 프로젝트별 참여자를 모아 봅니다
- **데이터 정리**
  - 중복 정리: 이름+회사가 같은 항목을 묶어, 남길 항목 선택 후 병합(활동기록·빈 항목 자동 합침)
  - 말소 정리: 말소로 표시된 데이터를 모아 완전 삭제(또는 복구)
- **내보내기**: 전체 데이터를 엑셀(.xlsx)로 저장

## 데이터 보관

입력한 데이터는 기본적으로 브라우저의 `localStorage`에 저장됩니다.
- 같은 브라우저에서는 새로 열어도 데이터가 유지됩니다.
- 다른 PC/브라우저로 옮기거나 백업하려면 **내보내기**로 엑셀을 저장하세요.

## PC 간 공유 (구글시트 연동)

여러 PC가 같은 데이터를 공유하려면 상단 **☁ 동기화**에서 구글시트(Apps Script 웹앱)를 연결하세요.
설정 방법은 **[SHARING.md](SHARING.md)**, 붙여넣을 스크립트는 **[google-apps-script.gs](google-apps-script.gs)** 참고.
동기화하면 시트와 내 데이터를 합쳐 양쪽을 최신 상태로 맞춥니다(같은 항목은 더 최근 수정본 유지).

## 배포 (GitHub Pages)

`main` 또는 작업 브랜치에 푸시하면 `.github/workflows/pages.yml`이 자동 배포합니다.
최초 1회만 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정하면 됩니다.
주소: `https://<사용자>.github.io/<저장소>/`

## 엑셀 양식

권장 헤더(첫 줄): `회사 · 이름 · 직책 · 협업업무 · 활동기록 · 키워드 · 상태`

- 열 순서는 자유이며, 비슷한 헤더명(예: `업체명`, `담당자`, `직급`)도 자동 인식합니다.
- **활동기록** 한 칸에 여러 건은 줄바꿈 또는 `;` 로 구분, 한 건은 `날짜 | 채널 | 내용` 형식을 권장합니다.
- **상태** 열에 `말소`(또는 해지/만료)라고 적으면 말소 데이터로 분류됩니다.
- 가져오기 시 이름+회사가 같은 기존 데이터가 있으면 자동으로 병합됩니다.

'데이터 추가 → 엑셀 파일' 탭의 **양식 다운로드** 버튼으로 예시 파일을 받을 수 있습니다.

## 디자인

흰 배경 · 진회색 텍스트 · 블루 강조의 미니멀/모던 스타일. 한글 폰트는 Pretendard를 사용합니다.
(엑셀 처리는 SheetJS, 폰트는 Pretendard를 CDN으로 불러오므로 최초 실행 시 인터넷 연결이 필요합니다.)
