데이터 수정

☁ 클라우드 동기화 (구글시트)

여러 PC가 같은 구글시트를 공유합니다. 동기화하면 시트와 내 데이터를 합친 뒤 양쪽을 최신 상태로 맞춥니다(같은 항목은 더 최근에 수정한 내용 유지).

최초 설정(1회): 구글시트 → 확장 프로그램 → Apps Script → 저장소의 google-apps-script.gs 내용 붙여넣기 → 배포(웹앱, 액세스: 모든 사용자) → 나온 /exec URL을 위에 입력하세요. 자세한 단계는 저장소 SHARING.md 참고.
